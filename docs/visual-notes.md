# Visual Notes and Diagrams

Diagrams should clarify a relationship that prose cannot show as quickly.

## Choose the smallest visual

- Table for exact mappings or comparisons.
- Flow for an event sequence.
- Tree for hierarchy or ownership.
- Timeline for changing state.
- Wireframe for layout.

Skip a diagram for a single fact or simple list.

## Excalidraw quality checklist

- Use a dark canvas with light text when that is the chosen vault convention.
- Wrap and measure text before sizing containers.
- Size boxes from measured text plus padding; do not place labels at blind fixed offsets.
- Route connectors around text and preserve consistent spacing.
- Check scene geometry for overlaps and out-of-bounds text.
- Open the saved drawing in the actual Obsidian Excalidraw view and capture/inspect it before calling it complete.
- If rendered verification is unavailable, say so explicitly.

The editable drawing belongs in the vault so it can be opened normally; an exported image is a derivative, not the canonical source.
