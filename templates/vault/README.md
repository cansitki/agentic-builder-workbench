# Vault Template

Copy these files into an Obsidian vault, rename the examples, and connect them with wikilinks.

Rules:

- Keep one general `To Do List.md`.
- Search before creating a note.
- Create atomic durable notes, then link them from `Vault Index.md` and the relevant project hub.
- Use daily notes for chronological events, not as the only home of important decisions.
- Keep `## Links Inbox` as the final section of each daily note.
- Never store credentials, seed phrases, private keys, recovery codes, or raw customer data in the vault.
