# Markdown as Memory

Plain Markdown is useful agent memory because it is portable, diffable, searchable, linkable, and readable without a proprietary database.

## Good memory files

- have one clear purpose;
- name their owner/source of truth;
- record update or verification dates;
- distinguish fact, decision, inference, and task;
- link to detail instead of duplicating it;
- remain small enough to review.

## What Markdown does not solve

- truthfulness;
- stale facts;
- permissions;
- secret storage;
- retrieval design;
- conflicting writers;
- backup and restore.

Files are durable memory only when a workflow maintains them.
