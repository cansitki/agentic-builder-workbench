# Personal AI OS

A personal AI operating system is a shared workspace in which a human and agents maintain projects, commitments, knowledge, and execution evidence.

## Components

- A human-readable vault or knowledge base.
- Durable agent guidance.
- A single task source of truth.
- Project repositories with local instructions.
- Daily logs and decision records.
- Reusable skills for repeated work.
- Connectors only for live external context that cannot live safely in files.
- Verification, backup, and recovery.

The human owns intent, priorities, and high-impact authority. Agents reduce the cost of inspection, synthesis, implementation, and maintenance.

## The compounding loop

```text
work creates evidence
  → evidence updates project state
  → durable learning enters the vault
  → better context improves future work
```

The system fails when it becomes an unreviewed transcript archive. The durable layer should contain decisions and useful knowledge, not every sentence generated along the way.
